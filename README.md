# 카드메이트

주제를 입력하면 인스타그램용 1:1 카드뉴스 초안을 만드는 로컬 웹 도구입니다.

## 실행

`dist/index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도 설치나 서버가 필요하지 않습니다.

## 기능

- 주제, 대상, 문체, 카드 수를 반영한 5~10장 구성 생성
- 카드별 제목·설명 편집
- 4가지 컬러 테마와 3가지 레이아웃
- 카드 추가, 이전·다음 카드 탐색, 확대·축소
- 현재 카드 1080×1080 PNG 저장
- 인스타그램 캡션 복사
- 브라우저 자동 저장

모든 생성과 편집은 브라우저 안에서 처리되며 입력한 내용은 외부로 전송되지 않습니다.
