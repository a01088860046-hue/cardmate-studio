# 김영숙부동산 스튜디오

네이버 블로그 초안 작성과 인스타그램 카드뉴스 제작을 한곳에서 사용하는 정적 웹 스튜디오입니다.

## 기능

- 블로그 글 기획, 초안 편집, 검색 품질 점검 및 발행 준비
- 브라우저 초안 자동 저장
- 인스타그램 카드뉴스 생성, 카드별 편집 및 순서 변경
- 카드 PNG와 전체 ZIP 저장
- 게시물 캡션과 해시태그 복사

모든 생성과 편집은 브라우저 안에서 처리되며 입력한 내용은 외부로 전송되지 않습니다.

## 배포

`main` 브랜치가 변경되면 GitHub Actions가 GitHub Pages에 자동으로 배포합니다.
